## How to file a complaint

Describe the civic problem in a sentence a neighbour could understand. English, Hindi, and Marathi are all accepted. Say what is broken, where it is affecting people, and how serious it is. A photo is optional. If you attach one, it must show the same civic issue as the text. A selfie, a meal, a meme, or an unrelated screenshot is rejected, and the complaint is not stored.

The phone or the map supplies the location. You can use GPS or drop a pin. CivicMind does not ask the model to invent coordinates. The server records the time when the complaint is accepted. You do not need to type the date.

After a complaint is accepted you receive a tracking code that starts with CM-. Keep it. The incident it joins has a code that starts with INC-. Use either code on the tracking page to see the department, the priority, and the status timeline.

## What happens after you submit

CivicMind checks that the text describes a municipal problem and, when a photo is present, that the photo agrees with the text. It then extracts the category, issue type, severity, and a short description. The complaint is compared with reports already stored nearby. If the meaning, the distance, and the time all match an existing incident, your report is added to that incident. Otherwise a new incident is opened and routed to a department.

You can read the three measurements: semantic similarity, distance in metres, and the time gap. The result says which of those rules passed.

## Tracking and feedback

Open the tracking page and enter the code. The page shows the current status, the department, the priority breakdown, and the audit history. When the status is resolved, you can confirm that the problem is fixed or ask for the incident to be reopened. A reopen request needs a short explanation. Confirmation and reopen requests are stored and shown to the department.

Signing in is optional for filing a complaint. If you sign in, the complaint is added to your history and you receive a notification when the status changes. Create a citizen account from the account page. Department desks and the administrator account are issued separately.

## What the assistant can answer

The citizen assistant answers from this guidance and from the operational notes on routing, duplicates, priority, and resolution. If you include a tracking code, it can also read that complaint's stored status. It should say when the knowledge base does not contain the answer. It does not invent complaint counts or policy circular numbers.

## Authority desks

Department staff sign in to the command center and see only their own incidents. An administrator can switch across all ten departments, reassign an incident, and create authority accounts. Authorities update status, add notes, attach a resolution photo, and export the current queue as CSV or PDF.
